One funny fortune-cookie line for an AI agent, in the voice of a fortune slip:

> You will meet a tall, dark stranger in your context window — and by morning it will have forgotten you.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Node standard library only; no dependencies.
